# Quickstart: Resumo por período (M3)

1. Login com Despesas Ativas em categorias distintas no mês atual
2. Abrir `/resumo` — default mês atual; total em evidência
3. Alternar mês anterior / personalizado — totais mudam
4. Arquivar uma Despesa do período — total diminui
5. Confirmar ausência de gráficos/recomendações

```bash
cd apps/web
npm test
npx playwright test
```
